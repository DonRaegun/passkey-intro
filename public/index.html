02 / Decisions

가계부에서 내린 판단 세 가지

기능을 넣는 것보다 “무엇을 일부러 하지 않았나”를 남기는 쪽에 더 신경 썼습니다. 가계부 개발 기록에서 골랐습니다.

v2.1 · 알림 읽기

토스 알림이 안 들어왔다

문제
금액이 알림 제목에만 있는데, 읽기 규칙은 본문에서만 금액을 찾아 버렸다.
고민
토스 전용 규칙을 만들까, 제목과 본문을 합쳐 읽을까.
선택
합쳐서 읽기. 형식마다 규칙을 늘리는 것보다 다른 앱에도 통한다.
일부러 안 한 것
외화 결제·자동이체 알림은 읽지 않음. 잘못 넣느니 직접 입력이 낫다.
v2.17.1 · 통계

결제수단 막대에서 정산을 뺄까

문제
정산을 뺐더니 카드 막대가 실제 카드 값보다 작게 나왔다.
고민
카드에서 빼기 / 받은 계좌에서 빼기 / 빼지 않기.
선택
빼지 않기. 이 막대는 “돈이 어떤 방식으로 나갔나”를 보는 것이고, 화면에 “정산은 빼지 않은 값”이라고 밝혀 둔다.
v2.9 ~ 2.10 · 화면

예뻐 보이던 효과를 걷어냈다

문제
원 그래프를 누르면 조각이 반짝이는 효과가 지나치다는 의견을 받았다.
선택
색이 강조되는 정도만 남기고 나머지는 뺐다.
배운 점
화면 효과는 넣는 것보다 빼는 쪽이 더 어렵다. 처음엔 예뻐 보여도 의견을 받으면 대부분 걷어냈다.

05 / Limits

아직 못 한 것

숨기지 않고 적어 둡니다. 가계부 개발 기록의 “남은 한계”에서 골랐습니다.

  • 가계부 · 플랫폼아이폰에서는 결제 알림 자동 입력이 되지 않습니다 (안드로이드 앱만).
  • 가계부 · 알림 형식외화 결제, 카드대금·자동이체 알림은 읽지 않고, 네이버페이·카카오페이·교통카드 형식은 확인하지 못했습니다.
  • 가계부 · 테스트자동 UI 테스트가 없습니다. 화면은 브라우저와 에뮬레이터에서 직접 확인했습니다.
  • 가계부 · 업데이트앱 안 업데이트 파일의 무결성(체크섬)은 확인하지 않고, 주소를 허용 목록으로만 거릅니다.
